# CLAUDE.md — AI 學習筆記站

這份文件是給 AI 助手看的專案規則。開始修改或新增任何內容前，請先完整讀完。

## 1. 專案目的

這是一個個人的「AI 課程學習筆記」靜態網站。每一頁是一則短筆記，用來整理上課學到的 AI 概念（例如 RAG、AI Agent）。

目標：之後只要依照本文件，就能在幾分鐘內新增一則風格一致的新筆記，不需要重新設計。

讀者是未來的自己和同學，所以內容要「短、清楚、能複習」。

## 2. 技術限制

- 純靜態網站：只用 HTML 和 CSS，不用 JavaScript、不用打包工具、不用框架。
- 所有頁面共用同一份 `style.css`，不要在頁面內寫行內樣式或另一份 CSS。
- 不引入外部圖片或函式庫。字型只允許用 `<head>` 範本中已有的 Google Fonts 連結。
- 使用 GitHub Pages 發佈，從 repository 根目錄部署。

## 3. 檔案結構

```
ai-notes/
├── CLAUDE.md            # 本文件
├── README.md            # 給人看的簡介
├── index.html           # 首頁，列出所有筆記
├── style.css            # 全站唯一樣式表
├── templates/
│   └── note.html        # 新增筆記時複製這份
└── notes/
    ├── rag-basics.html
    └── ai-agent-basics.html
```

## 4. 命名與放置規則

- 筆記一律放在 `notes/`，檔名用小寫英文與連字號，例如 `prompt-engineering.html`。
- 不使用中文、空白或大寫當檔名。
- 檔名要能看出主題，不要用 `note1.html` 這種名稱。
- 不要新增其他資料夾，除非使用者明確要求。

## 5. 頁面結構

每則筆記必須由 `templates/note.html` 複製而來，保持以下順序：

1. 頁首：站名連結回首頁
2. `<h1>` 筆記標題
3. 中繼資訊：日期（YYYY-MM-DD）與標籤
4. 摘要區塊 `.summary`：一到兩句話說完重點
5. 正文：用 `<h2>` 分段，每段不超過 5 句話
6. 頁尾：回首頁連結

## 6. 風格規則

- 顏色、字體與間距只能使用 `style.css` 開頭 `:root` 裡定義的變數，不要寫死色碼。
- 版面寬度由 `.wrap` 控制，不要在頁面中另外設定寬度。
- 強調文字用 `<mark>`（螢光筆效果），一頁最多 3 處。
- 程式碼用 `<pre><code>`，行內用 `<code>`。
- 不使用 emoji 當裝飾。

## 7. 新增筆記的步驟（照做即可）

1. 複製 `templates/note.html` 到 `notes/<英文檔名>.html`。
2. 替換所有 `{{...}}` 佔位符：標題、日期、標籤、摘要、正文。
3. 打開 `index.html`，在筆記列表 `<ul class="note-list">` 的最上方新增一個 `<li>`，格式與既有項目完全相同。
4. 確認頁面中的 CSS 路徑是 `../style.css`，首頁連結是 `../index.html`。
5. 檢查：沒有剩下的 `{{` 字樣、連結都能點、標題與首頁列表一致。

## 8. 內容與語氣

- 使用繁體中文，句子簡短，用「你」稱呼讀者。
- 先講結論，再講原因。
- 專有名詞第一次出現時，附上英文，例如：檢索增強生成（RAG）。
- 不確定的內容要寫「待確認」，不要編造。
- 不得直接貼上整段他人文章；要用自己的話整理，並在文末註明參考來源。

## 9. AI 修改時的禁止事項

- 不要修改既有筆記的內容，除非使用者明確指定。
- 不要更動 `style.css` 的變數名稱。需要新樣式時，先問使用者。
- 不要刪除或重新命名既有檔案。
- 不要新增與筆記無關的功能（留言、搜尋、動畫等）。

## 10. 本機預覽與發佈

- 預覽：直接用瀏覽器開啟 `index.html` 即可。
- 發佈：推送到 GitHub 的 `main` 分支，並在 repository 的 Settings → Pages 選擇從 `main` 分支根目錄部署。
