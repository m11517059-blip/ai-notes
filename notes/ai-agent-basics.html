AI Agent 的三種基本模式

2026-11-05｜AI Agent、LLM

AI Agent 不是只回答一次，而是會自己檢查、使用工具、拆解任務。這三件事分別對應 Reflection、Tool Use 和 Planning。

Reflection（反思）

模型先產生初稿，再自己檢查並修改。適合寫作、潤稿這類可以反覆改進的任務。

Tool Use（使用工具）

模型判斷何時該呼叫外部工具，例如計算機、搜尋或資料庫，再把結果整合進答案。適合需要精確數字或最新資料的任務。

Planning（規劃）

模型先把大任務拆成小步驟，再逐步執行。適合複雜、需要多個階段才能完成的任務。

怎麼選

先問自己：任務缺的是品質、資料，還是步驟？缺品質用 Reflection，缺資料或計算用 Tool Use，步驟太多用 Planning。實務上三者常常組合使用。
