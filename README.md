## 發佈到 GitHub Pages

1. 在 GitHub 建立新的 repository，把這個資料夾的所有檔案上傳。
2. 到 repository 的 Settings → Pages。
3. Source 選 `Deploy from a branch`，分支選 `main`，資料夾選 `/ (root)`，儲存。
4. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repository 名稱>/`。
